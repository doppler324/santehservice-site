ГЛАВНАЯ — ПАКЕТ ДЛЯ БИТРИКСА (формы через модуль «Веб-формы»)

1. КОПИРОВАНИЕ (корень сайта)
   index.php                         -> /index.php
   local/templates/santehservice/*   -> то же место (header.php, footer.php, css/, js/, images/home/, include/, components/)
   local/php_interface/home_webform_events.php -> /local/php_interface/
   В /local/php_interface/init.php добавьте строку:
   require_once($_SERVER["DOCUMENT_ROOT"]."/local/php_interface/home_webform_events.php");

2. СОЗДАНИЕ ВЕБ-ФОРМЫ (Сервисы -> Веб-формы -> Настройки форм -> Добавить)
   Название: Заявка с сайта (SID формы Битрикс назначает сам, например SIMPLE_FORM_1 — он прописан в home_webform_events.php)
   Сайт: отметьте ваш сайт.  Индекс сортировки: любой.
   Вкладка «Почтовое событие»: создать новое почтовое событие + шаблон (FORM_FILLING_SIMPLE_FORM_1),
   в шаблоне укажите «Кому» (email для заявок). В тексте письма удобно использовать #RS_FORM_ID#, #RS_RESULT_ID#
   и поля вопросов по SID: #NAME#, #PHONE#, #MESSAGE#, #SOURCE#, #PAGE#.
   Статусы: оставьте «Новая» по умолчанию (можно добавить «В работе», «Закрыта»).
   CAPTCHA в настройках формы ОТКЛЮЧИТЕ (шаблон её не выводит, заявки не пройдут).
   Права: группе «Все пользователи» — право «Заполнение» (создание результата);
   просмотр результатов — только администраторам.

3. ВОПРОСЫ ФОРМЫ (сохраните форму, затем «Вопросы» -> Добавить). SID важны — по ним шаблон находит поля:
   NAME     Имя                  тип text      обязательный
   PHONE    Телефон              тип text      обязательный
   MESSAGE  Сообщение            тип textarea  необязательный (в блоке «Контакты» шаблон требует заполнения сам)
   SOURCE   Источник заявки      тип text      (шаблон заполняет скрыто: «Баннер главной; IP …»)
   PAGE     Страница             тип text      (скрыто, URL страницы)
   AGREE    Согласие на обработку тип checkbox, вариант ответа «Да», обязательный
   Если SID вопроса задать нельзя (упрощённый режим), шаблон найдёт вопрос по заголовку: Имя, Телефон, Сообщение,
   Источник, Страница, Согласие. Заголовки должны начинаться с этих слов.
   У каждого вопроса должен быть ровно один ответ нужного типа.

4. ПОСЛЕ УСТАНОВКИ
   - Сбросьте кеш (Настройки -> Производительность -> Очистить кеш), если включён композитный сайт —
     исключите страницу из композита или оставьте динамическую область для формы (в форме есть sessid).
   - Отправьте тестовую заявку: результат появится в Сервисы -> Веб-формы -> Результаты -> «Заявка с сайта».
   - Проверьте почтовые настройки сервера (SMTP, SPF/DKIM), иначе письма могут уходить в спам.
   - Если SID формы другой — измените его в include/contacts-block.php и index.php через homeWebFormId("ВАШ_SID")
     или поправьте значение по умолчанию в home_webform_events.php.

5. ЗАЩИТА ОТ СПАМА
   В шаблоне скрытое поле-ловушка «website»; заполненная заявка отклоняется обработчиком onBeforeResultAdd.
   Дополнительно можно включить CAPTCHA в настройках веб-формы.

6. КОНТАКТЫ
   Адрес, координаты карты и email в include/contacts-block.php — замените на реальные.
   Названия пунктов меню могут отличаться в версиях Битрикса.
